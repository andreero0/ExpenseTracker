# ExpenseTracker v1.1 Release Notes

**Release Date**: 2025-11-19

**Previous Version**: 1.0.0

## 🎉 What's New

Version 1.1 brings **8 major new features** that transform ExpenseTracker into a comprehensive personal finance management platform with advanced capabilities for automation, customization, and security.

---

## ✨ New Features

### 1. 🌙 Dark Mode
**Fully customizable dark mode for all 4 themes**

- Toggle between light and dark variants for Coffee, Forest, Purple, and Ocean themes
- Automatic theme persistence using AsyncStorage
- Beautiful dark color schemes optimized for readability
- System status bar automatically adapts to theme
- Accessible via new Settings screen

**Files Added**:
- `mobile/context/ThemeContext.jsx` - Theme management system
- `mobile/app/(root)/settings.jsx` - Settings screen with theme controls
- `mobile/assets/styles/settings.styles.js`

**Updated**:
- `mobile/constants/colors.js` - Added 4 dark theme variants
- `mobile/app/_layout.jsx` - Integrated ThemeProvider
- `mobile/app/(root)/index.jsx` - Uses theme context

### 2. 🔐 Biometric Authentication
**Secure app access with Face ID and Touch ID**

- Support for Face ID (iOS), Touch ID (iOS), and Fingerprint (Android)
- Easy setup/disable flow with permission handling
- Graceful fallback to device passcode
- Test authentication feature
- Fully native implementation using expo-local-authentication

**Files Added**:
- `mobile/app/(root)/biometric-setup.jsx` - Biometric configuration screen
- `mobile/assets/styles/biometric.styles.js`

**Dependencies**: `expo-local-authentication`

### 3. 🔄 Recurring Transactions
**Automate your regular expenses and income**

- Create recurring transactions with 6 frequency options:
  - Daily, Weekly, Bi-weekly, Monthly, Quarterly, Yearly
- Pause/resume recurring transactions
- Set optional end dates
- Backend cron jobs automatically process due transactions
- Full CRUD support with beautiful mobile UI

**Backend Implementation**:
- `backend/src/controllers/recurringController.js` - Full CRUD + processing logic
- `backend/src/routes/recurringRoute.js` - API endpoints
- `backend/src/services/cronService.js` - Cron job scheduler
- Database table: `recurring_transactions` with indexes

**Mobile Implementation**:
- `mobile/app/(root)/recurring.jsx` - Complete recurring transactions UI
- `mobile/assets/styles/recurring.styles.js`

**Cron Schedule**:
- Daily job: Midnight (00:00)
- Hourly check: Every hour (for testing/development)

### 4. 💱 Multi-Currency Support
**Track expenses in 12 major currencies**

- Supports USD, EUR, GBP, JPY, CAD, AUD, CHF, CNY, INR, BRL, ZAR, MXN
- Currency preference persisted per user
- Beautiful currency selection UI with symbols and names
- All new transactions use selected currency

**Files Added**:
- `mobile/app/(root)/currency.jsx` - Currency settings screen

**Future Enhancement**: Add currency conversion API integration

### 5. 📊 CSV/PDF Export
**Export your transaction history**

- Export all transactions to CSV format
- Share exported files via native share sheet
- Formatted with headers: Date, Title, Amount, Category
- Automatic filename with date stamp
- PDF export placeholder (coming soon)

**Files Added**:
- `mobile/app/(root)/export.jsx` - Export functionality screen

**Dependencies**: `expo-file-system`, `expo-sharing`

### 6. 📸 OCR Receipt Scanning
**Scan receipts using your camera (Coming Soon)**

- Take photos or select from gallery
- Integration-ready for Google Vision API
- Pre-filled transaction creation from receipt data
- Beautiful image preview and editing
- Complete skeleton implementation

**Files Added**:
- `mobile/app/(root)/scan-receipt.jsx` - OCR scanning screen

**Dependencies**: `expo-image-picker`, `expo-camera`

**Setup Required**: Google Vision API key (see `INSTALL_DEPENDENCIES.md`)

### 7. 📴 Offline Mode
**Use the app without internet connection**

- Save transactions locally when offline
- Automatic sync when connection restored
- Pending sync counter
- Manual sync trigger
- Clear cache functionality
- Beautiful offline status indicators

**Files Added**:
- `mobile/app/(root)/offline.jsx` - Offline mode settings

**Implementation**: Uses AsyncStorage for local persistence

### 8. 🏦 Plaid Bank Connections (Integration Guide)
**Connect your bank accounts (Guide Provided)**

- Complete Plaid integration documentation
- Automatic transaction sync from bank accounts
- Sandbox testing credentials included
- Production deployment checklist
- Security best practices

**Files Added**:
- `PLAID_INTEGRATION.md` - Complete integration guide with code samples

**Dependencies**: `plaid` (backend), `react-native-plaid-link-sdk` (mobile)

## 🚀 Installation

### Quick Start
```bash
# Backend
cd backend
npm install
# Add new environment variables to .env (see INSTALL_DEPENDENCIES.md)
npm run dev

# Mobile
cd mobile
npm install
npx expo prebuild --clean  # Required for native modules
npm start
```

### Environment Variables Required
```env
# Backend (.env)
ENABLE_CRON=true
API_URL=http://localhost:5001
GOOGLE_VISION_API_KEY=optional
PLAID_CLIENT_ID=optional
PLAID_SECRET=optional
PLAID_ENV=sandbox
```

## 🔄 Migration Notes

### From v1.0 to v1.1

1. **Database**: Run the app once to auto-create new tables
2. **Dependencies**: Run `npm install` in both backend and mobile
3. **Mobile**: Run `npx expo prebuild --clean` for native modules
4. **Environment**: Add new environment variables
5. **iOS**: Run `cd ios && pod install` if using biometric auth

### Breaking Changes
**None** - v1.1 is fully backward compatible with v1.0
