## 💰 Managing Transactions

### Adding a Transaction Manually

1. **Tap the "+ Add" button** on the home screen
2. **Select transaction type**:
   - Tap "Expense" for money spent
   - Tap "Income" for money received
3. **Enter the amount** (e.g., 45.50)
4. **Add a description** (e.g., "Grocery shopping at Whole Foods")
5. **Choose a category**:
   - Food & Drinks
   - Shopping
   - Transportation
   - Entertainment
   - Bills
   - Income
   - Other
6. **Tap "Save"**

Your transaction is now tracked!

### Editing a Transaction

1. **Find the transaction** in your list
2. **Tap the pencil icon** (edit button)
3. **Modify** any details:
   - Change the amount
   - Update the description
   - Switch category
   - Change between expense/income
4. **Tap "Update"**

### Deleting a Transaction

1. **Find the transaction** you want to remove
2. **Tap the trash icon**
3. **Confirm deletion**

## 🤖 AI-Powered Statement Import (Game Changer!)

Import **entire months** of transactions in seconds!

### How to Import Your Bank Statement

1. **Get your bank statement**
   - Download PDF from your bank's website
   - Or use paper statement (scan to PDF)

2. **In the app**:
   - Tap the **cloud upload icon** in the top right
   - Select "Choose PDF Statement"
   - Pick your bank statement file

3. **AI Processing** (takes 5-30 seconds):
   - AI reads your statement
   - Extracts ALL transactions automatically
   - Categorizes each transaction
   - Detects potential duplicates

4. **Review & Edit**:
   - Check the extracted transactions
   - Duplicates are marked with ⚠️ warnings
   - Uncheck any you don't want to import
   - Edit categories if needed

5. **Import**:
   - Tap "Import [X]" button
   - Done! All transactions added at once

### Supported Banks
✅ Chase, Bank of America, Wells Fargo, Citibank, Capital One, and most other banks

### Tips for Best Results
- Use **PDF statements** (not images)
- Ensure text is selectable in PDF
- One statement per upload
- Review before importing

## 🔍 Filtering Transactions

Never lose track of specific transactions!

### Using Filters

1. **Tap the filter icon** (funnel) on the home screen
2. **Choose a category**:
   - Select "All Categories" to see everything
   - Or pick specific category (Food, Shopping, etc.)

3. **Select a date range**:
   - **Today** - Today's transactions only
   - **This Week** - Last 7 days
   - **This Month** - Current calendar month
   - **Last 30 Days** - Rolling 30-day window
   - **All Time** - Everything ever recorded

4. **Tap "Apply Filters"**

The filter button shows a **red badge** when filters are active.

### Clearing Filters
Tap the filter icon → Tap "Reset" → Filters cleared!

## 💵 Budget Management

Set spending limits and track your progress.

### Creating a Budget

1. **Navigate to Budgets** screen
2. **Tap "Set Budget"**
3. **Select a category** (e.g., Food & Drinks)
4. **Enter monthly budget amount** (e.g., $500)
5. **Tap "Save Budget"**

### Understanding Budget Cards

Each budget shows:
- **Category name** with icon
- **Amount spent / Total budget** (e.g., $347.50 of $500.00)
- **Remaining amount** (e.g., $152.50 left)
- **Progress bar**:
  - 🟢 Green = On track
  - 🔴 Red = Over budget
- **Percentage used** (e.g., 69% used)

### Over-Budget Alerts

When you exceed a budget:
- Progress bar turns **red**
- Shows "**$X.XX over**" in red text
- Helps you adjust spending

### Editing/Deleting Budgets

1. **Find the budget card**
2. **Tap the trash icon**
3. **Confirm deletion**
4. **Create a new budget** with updated amount

## 📊 Analytics Dashboard

Visualize your spending patterns and gain insights!

### Accessing Analytics

**Tap the analytics icon** (graph) in the top right of home screen.

### What You'll See

#### 1. **Period Selector**
Toggle between:
- Week
- Month (default)
- Year

#### 2. **Statistics Cards** (4 key metrics)

**Total Expenses**
- This month's total spending
- ↑ ↓ % change vs last month
- Red indicates increase, green decrease

**Total Income**
- This month's total earnings
- ↑ ↓ % change vs last month
- Green indicates increase

**Average Expense**
- Average transaction amount
- Total transaction count

**Top Category**
- Your highest spending category
- Amount spent in that category

#### 3. **Spending by Category (Pie Chart)**

Beautiful color-coded breakdown:
- Each slice = One category
- Larger slice = More spending
- Tap to see exact amounts
- Shows percentage of total

**Color Legend**:
- 🔴 Food & Drinks
- 🔵 Shopping
- 🟢 Transportation
- 🟠 Entertainment
- 🟡 Bills
- 🟣 Income
- ⚪ Other

#### 4. **Spending Trends (Line Chart)**

6-month view of your expenses:
- X-axis: Months
- Y-axis: Dollar amounts
- Line shows spending over time
- Helps identify patterns

#### 5. **Category Breakdown List**

Detailed list showing:
- Color indicator
- Category name
- Total amount spent
- Percentage of total spending

### How to Use Analytics

**Monthly Review**:
1. Set period to "Month"
2. Check if expenses are trending up or down
3. Identify top spending categories
4. Compare to budgets

**Long-term Trends**:
1. View the 6-month line chart
2. Look for seasonal patterns
3. Spot unusual spikes
4. Track progress over time

## ❓ Frequently Asked Questions

### Can I use this on multiple devices?
Yes! Sign in with the same email/password on any device.

### Is my bank statement stored?
No. Statements are processed in memory and immediately discarded. We only keep the extracted transactions.

### What if AI categorizes incorrectly?
Simply edit the transaction and change the category. The AI learns from common patterns but you have full control.

### Can I export my data?
Currently, you can view all data in the app. Export features (CSV/PDF) coming soon!

### Does this work offline?
You need internet connection for syncing. Offline mode coming in future updates.

### How much does the AI feature cost?
The AI processing costs approximately $0.01-$0.05 per statement. This is extremely cost-effective for the time saved!

### What about recurring transactions?
Currently manual tracking. Auto-recurring feature coming soon!

## 🆘 Troubleshooting

### Statement Import Not Working
- Ensure PDF is selectable text (not scanned image)
- File size under 10MB
- Try a different statement format
- Check internet connection

### Transactions Not Showing
- Pull down to refresh
- Check if filters are active (red badge)
- Verify you're signed in
- Check internet connection

### Charts Not Loading
- Ensure you have transaction data
- Check selected time period
- Pull to refresh
- Restart app if needed

### Budget Not Updating
- Ensure transactions are categorized correctly
- Wait a few seconds for sync
- Pull to refresh
- Check internet connection
